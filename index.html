The open project

OpenCorral, built in the open.

The code, the design and the rules for changing them. OpenCorral is a local station that holds your result above the harnesses and models doing the work, and accepts nothing until the evidence passes. Why it exists is at opencorral.com.

Code on GitHub Contribute

Start.

You need Node 24.14.1 or later in the 24.x line. Python 3.10 or later is needed only for the conformance bench. The station listens only on your own machine, at http://127.0.0.1:4317.

To look around before using it on real work, seed a separate store of clearly labelled sample data and start the station against that.

git clone https://github.com/eigenforma/opencorral.git
cd opencorral
npm ci
npm run build
npm start

# or, with sample data
npm run demo
npm start -- --data-dir demo-data

How changes are judged.

The project holds its own code to the standard it asks of agents. The same rules apply whether a person or an agent wrote the change.

Tests seen failing first

A test for new behavior fails on the code before the change and passes after it. Guards that pin existing behavior are declared as guards.

Gates green

Type check, build, tests and the conformance bench pass locally and again in continuous integration.

Honest claims

Say what ran, what was inferred and what was not measured. Synthetic data is labelled synthetic.

A person approves

A human maintainer approves every merge. Reviews grade the change, never the person.
